# Create
Prefixes are stored in ~/.winebox/prefixes/

Each prefix contains:
- prefix/
- config.json

* The prefix names are basic: alphabet, hyphen (-), and period (.). The program suggests alternatives if something complex is used. Why? Because it's simply a Wine indicator, which the user needs to manage quickly. Applications within Wine are opened and managed in other ways, so the simpler, the better for the user. A flag that does this anyway would be a good idea

* The current Winebox version must be stored in the config.json file. Being able to update the program without causing problems is essential, and a command to perform this update would be very useful. Therefore, it should be configured now.
